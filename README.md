# TeacherReporter

Веб-приложение для школьных учителей для управления отчетами об оценках учеников.

## Технологический стек
- C# / ASP.NET Core 8 (MVC)
- MySQL + Entity Framework Core
- ASP.NET Core Identity
- jspreadsheet CE v4
- pdfmake / SheetJS

## Функции
- Редактор электронных таблиц, похожий на Excel, с вкладками, формулами и форматированием
- Цветовая кодировка оценок (русская система 1–5)
- Экспорт в PDF и Excel
- Панель администратора с управлением пользователями
- Чат поддержки с возможностью прикрепления файлов
- Переключение темной/светлой темы
- Русский интерфейс

## Настройка
1. Клонируйте репозиторий
2. Скопируйте `appsettings.example.json` в `appsettings.json`
3. Заполните строку подключения к MySQL~~~~
4. Запустите `dotnet ef database update`
5. Запустите `dotnet run`
6. Администратор по умолчанию: admin@school.com / admin123
